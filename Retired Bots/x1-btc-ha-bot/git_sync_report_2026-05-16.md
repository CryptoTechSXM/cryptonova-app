1. **The script isn't reachable.** Only four child folders are shared with Cowork (`0-tg-mt5-bot`, `1-btc-ha-bot`, `6-Quick-Scalp-NAS100`, `CryptoNite-Free-Signals`). 2. **No sandbox-side git fallback.** None of the four mounted child folders contain a `.git/` directory of their own, so a `git add / commit / push` from inside the sandbox is also impossible.
