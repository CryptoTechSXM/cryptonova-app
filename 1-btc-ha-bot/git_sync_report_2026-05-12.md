## Recommendation

For an unattended scheduled sync, the desktop computer-use path is the wrong tool — it requires a human at the keyboard to click "Allow". Two more reliable alternatives:

1. **Run the sync from Windows directly, outside the agent.** Schedule `python C:\CryptoNite-MT5-Bots\git_sync.py` via Windows Task Scheduler on a 30-minute interval. The scheduled task in Cowork can then be reduced to a "check that the last run succeeded" report (read the most recent `git_sync_report_*.md` or a log file the Windows scheduler writes, and surface failures).

2. **Move the script into a mounted folder and pre-grant access.** If `git_sync.py` (and a `.git/` checkout that contains all four bots) lived inside one of the mounted directories — and credentials were available in that directory via a git credential helper file — the agent could run it from the Linux sandbox without needing desktop approval. This is a larger restructure.

Option 1 is the smaller change and matches what unattended automation actually needs.
